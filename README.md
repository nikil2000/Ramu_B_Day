# 🎂 Happy Birthday Matti - Web Page

This cute, professional birthday webpage is ready to be hosted on **GitHub Pages**!

## 📁 Files in this Folder
- `index.html`: The entire webpage code (styles, animations, confetti, photo reveal, and continuous audio player).
- `birthday-song.mp4`: The continuous birthday song audio.
- `images/`: Contains the 7 photos (`photo1.jpeg` through `photo7.jpeg`).

---

## 🚀 How to Put It on GitHub Pages (Takes 2 Minutes)

1. Log in to [GitHub](https://github.com/).
2. Click **"+"** in the top right ➔ **New repository**.
3. Name it: `happy-birthday-matti` (make sure it is set to **Public**).
4. Click **Create repository**.
5. Click **"uploading an existing file"**.
6. Drag and drop:
   - `index.html`
   - `birthday-song.mp4`
   - the `images` folder (containing all 7 photos)
7. Click **Commit changes**.
8. Go to **Settings** ⚙️ ➔ **Pages** (on the left menu).
9. Under **Build and deployment > Branch**, select `main` (or `master`) and click **Save**.
10. Wait ~1 minute. Your live link will be:
    `https://<your-username>.github.io/happy-birthday-matti/`

Send that link to her on WhatsApp or Instagram! 🎉
